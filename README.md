# 🕹️ Wonder Boy - Proyecto Universitario

Este es un juego desarrollado para la carrera de **Tecnicatura en Desarrollo de Videojuegos** en **UNRaf**. 

## 📝 Descripción
Este proyecto consiste en la recreación técnica y artística de dos niveles clásicos, adaptados con una temática culinaria original.

## 🎮 Controles
*   **Moverse:**
    - Avanzar:
         Teclado: Tecla → / Tecla D.
         Mando: Flecha → / Palanca hacia la derecha.
    - Retroceder:
         Teclado: Tecla ← / Tecla A.
         Mando: Flecha ← / Palanca hacia la izquierda.
    - Saltar:
         Teclado: Tecla ↑ / Tecla W / Barra espaciadora.
         Mando: Flecha ↑ / Botón X (PlayStation).
        
*   **Lanzar cuchillo:**
         Teclado: Tecla Z / Tecla K.
         Mando: Botón ▢ (PlayStation) / Botón R2 (PlayStation).
